# ShareGather Design Documentation

This directory contains the detailed design and operational documentation for ShareGather.

- [Development](development.md): build, signing, localization, dependency, and verification conventions.
- [Privacy Policy](../PRIVACY.md): canonical English privacy-policy wording.
