# AGENTS.md

## Project Guidelines

This file records the development conventions and working guidelines for ShareGather.

## Product Constraints

- ShareGather is an iOS app that receives content shared from social media apps.
- The app must work completely offline.
- The app must not require user accounts or sign-in.
- Shared content should be saved locally for later review.
- Avoid server-side dependencies unless a future requirement explicitly changes this constraint.
- Treat user privacy and local data ownership as core product principles.

## Conventions

- Project requirements and technical conventions will be added as they are defined.
- Use English for documentation, code comments, identifiers, and user-facing text unless a requirement specifies otherwise.
- Design user-facing text and localization support for English and Traditional Chinese.
- Run appropriate tests and verification after completing changes.
